## 🚀 **My Projects**

Aquí tienes un resumen de algunos proyectos fullstack que he venido desarrollando, enfocados en resolver problemas reales con tecnologías modernas:

- **🐶 Rescue & Adoption Web App**  
  Plataforma solidaria para la adopción de perritos rescatados. Incluye autenticación con JWT, panel de administración, manejo de rescatados, blog de publicaciones y una tienda solidaria integrada para recaudar fondos.  
  Tecnologías: React, Tailwind CSS, Node.js, MongoDB, JWT, Express.

- **🛍️ Naldo’s Clothing Store**  
  E-commerce de ropa masculina con diseño moderno, filtros de productos, carrito de compras, vista previa de productos (modal), y una sección solidaria que comunica el impacto positivo de cada compra.  
  Tecnologías: React, Tailwind CSS, Context API, LocalStorage.

- **📦 Admin Dashboard para Tienda**  
  Panel de administración completo para gestionar productos, publicaciones y rescates desde el frontend. Incluye CRUD con formularios reactivos y control de acceso según roles (admin/user).  
  Tecnologías: React, Tailwind, Fetch API, MongoDB.

- **🌐 Portfolio Profesional**  
  Portafolio como desarrollador Front-End que incluye una landing visualmente atractiva, sección de proyectos, tecnologías dominadas, y una experiencia de usuario optimizada para web.  
  Tecnologías: HTML, CSS, JS, React, Tailwind CSS.
